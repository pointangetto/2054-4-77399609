## 📖 Overview
<a id="overview"></a>

**HiView** is a powerful, free desktop application developed by the HiRISE team at the University of Arizona, specifically designed to view extremely high-resolution imagery such as HiRISE JP2 (JPEG2000) files. The latest version is optimized for efficient exploration of large scientific images captured during Mars orbital missions.

HiView enables precise visual inspection of planetary data, making it an ideal choice for researchers, students, and space-imaging enthusiasts. With its comprehensive feature set, users can enjoy full functionality without any limitations, focusing on scientific image viewing rather than general photo editing.
